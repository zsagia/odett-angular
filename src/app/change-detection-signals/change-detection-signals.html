✨ Miért jobb a Signal?

⚡
Finom-granularitású reaktivitás

Csak az a komponens frissül, ami ténylegesen használja a signal-t

🎯
Egyszerűbb használat

Nincs szükség immutable pattern-ekre vagy ChangeDetectorRef-re

🚀
Jobb teljesítmény

Angular tudja pontosan, hogy mi változott, nem kell mindent ellenőrizni

🔗
Computed értékek

A completedCount automatikusan frissül, ha az items változik

🔍 Signal használata:
// Létrehozás
items = signal<Item[]>([...]);

// Olvasás (mint függvény!)
const allItems = this.items();

// Frissítés
this.items.update(current => [...current, newItem]);

// Computed
completedCount = computed(() => 
  this.items().filter(i => i.completed).length
);

📊 Összehasonlítás

Jellemző Default OnPush Signals ✨
Teljesítmény ❌ Lassú ✅ Gyors ✅✅ Leggyorsabb
Egyszerűség ✅ Egyszerű ❌ Bonyolult ✅✅ Nagyon egyszerű
Immutable pattern ❌ Nem kell ✅ KÖTELEZŐ ❌ Nem kell
Automatikus optimalizálás ❌ Részben ✅✅ Teljes

🎓 Mit tanultál?

  • ✅ Default CD: Mindent ellenőriz, egyszerű de lassú
  • ✅ OnPush CD: Gyors, de immutable pattern-t igényel
  • ✅ Signals: A legjobb mindkét világból - gyors ÉS egyszerű!
