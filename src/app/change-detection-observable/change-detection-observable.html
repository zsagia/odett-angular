📡 Mi történik Observable-lel?

A BehaviorSubject egy reaktív Observable, és az async pipe automatikusan subscribe-ol rá és továbbítja az értéket a child komponensnek.

💡 Kulcs megértés:

❌ Mutáció + Observable:
- BehaviorSubject.next() emit-el
- Async pipe megkapja az értéket
- DE a tömb referenciája azonos
- → Child OnPush NEM frissül!
- Observable sem varázs - kell immutable pattern!

✅ Immutable + Observable:
- BehaviorSubject.next() emit-el ÚJ tömböt
- Async pipe továbbítja az ÚJ referenciát
- → Child OnPush frissül!
- Observable + immutable = reaktív és hatékony!

🔍 BehaviorSubject használata:
// BehaviorSubject létrehozása
private itemsSubject = new BehaviorSubject<Item[]>([...]);
items$ = this.itemsSubject.asObservable();

// Template-ben: async pipe
@if (items$ | async; as items) {
  <app-item-list [items]="items" />
}

// ❌ Mutáció - NEM működik
mutateItem() {
  const items = this.itemsSubject.value;
  items[0].completed = !items[0].completed;
  this.itemsSubject.next(items); // Azonos referencia!
}

// ✅ Immutable - működik
updateImmutable() {
  const newItems = this.itemsSubject.value.map(...);
  this.itemsSubject.next(newItems); // ÚJ referencia!
}

⚠️ Fontos: Az Observable és async pipe önmagukban NEM oldják meg az OnPush problémáját - még mindig kell immutable pattern!

📊 Observable vs BehaviorSubject - Különbségek
🤔 Mi a különbség?
📡 Observable
  • ✅ Általános reaktív stream
  • ❌ Nincs kezdőérték
  • ❌ Subscribe után nem ad értéket azonnal
  • ✅ Cold: minden subscribe új execution-t indít
  • ✅ Példa: HTTP kérések, események
const obs$ = new Observable(subscriber => {
  subscriber.next('érték');
});

// Subscriber nem kap azonnal értéket!
obs$.subscribe(val => console.log(val));
🎯 BehaviorSubject
  • ✅ Observable + State
  • ✅ Van kezdőérték
  • ✅ Subscribe után azonnal ad értéket
  • ✅ Hot: minden subscriber ugyanazt az execution-t látja
  • ✅ .value - aktuális érték lekérése
  • ✅ Példa: State management, cache
const subject = new BehaviorSubject('kezdő');

// Subscriber AZONNAL megkapja a 'kezdő' értéket!
subject.subscribe(val => console.log(val));

subject.next('új érték'); // Minden subscriber értesül
🎯 Mikor melyiket használd?
Használati eset Observable BehaviorSubject
HTTP kérés (egyszeri adat) ✅ Ajánlott ❌
Event stream (click, input, websocket) ✅ Ajánlott ❌
Nincs kezdőérték ✅ Observable ❌
State management (alkalmazás állapot) ❌ ✅ Ajánlott
Cache (kezdőértékkel) ❌ ✅ Ajánlott
Aktuális érték lekérése (.value) ❌ ✅ Ajánlott
Új subscriber azonnal kapjon értéket ❌ ✅ Ajánlott

📌 Összefoglalás:
Az Observable egy stream, amely idővel érkezhet adatokkal.
A BehaviorSubject egy state container, amely mindig tartalmaz egy aktuális értéket.

Ebben a demo-ban: BehaviorSubject-et használunk, mert state-et kezelünk (items lista).
