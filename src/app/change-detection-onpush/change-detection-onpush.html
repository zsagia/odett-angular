🎯 Mi történik?

Az <app-item-list> komponens OnPush stratégiát használ.

OnPush Change Detection: A child komponens CSAK akkor frissül, ha az @Input() property REFERENCIÁJA megváltozik!

💡 Kulcs megértés:

❌ Mutáció gomb:
- Parent template frissül → Parent számláló nő a képernyőn
- Child ngDoCheck fut → számláló változó nő a memóriában
- DE! Child template NEM frissül (OnPush + azonos @Input ref)
- → Child számláló NEM nő a képernyőn!
- OnPush = kevesebb template frissítés = jobb teljesítmény!

✅ Immutable gomb:
- Parent template frissül → Parent számláló nő
- Child ngDoCheck fut + ÚJ @Input referencia
- → Child template IS frissül
- → Child számláló IS nő a képernyőn!
- ÚJ referencia → Angular észreveszi → UI frissül!

❌ NEM működik (setTimeout-ban):
setTimeout(() => {{ '{' }}
  item.completed = !item.completed; // Mutáció
  // Nincs template esemény → Nincs CD → UI nem frissül!
{{ '}' }}, 1000);
✅ Működik (immutable):
setTimeout(() => {{ '{' }}
  this.items = this.items.map(...); // Új tömb
  // ÚJ referencia → OnPush észreveszi a következő CD-nél!
{{ '}' }}, 1000);

⚠️ OnPush gyorsabb, de immutable pattern-t igényel külső változásoknál!

🔜 Következő lépés: Signals!

A Signal API megoldja ezt a problémát - reaktív, automatikusan frissül, és nincs szükség immutable pattern-ekre!
